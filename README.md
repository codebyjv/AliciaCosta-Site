# 🌸 Alicia Costa - Studio Website

Este repositório contém o código-fonte do **site onepage** desenvolvido para o **Studio Alicia Costa**, um espaço dedicado à beleza e bem-estar.  
O projeto foi criado com foco em simplicidade, elegância e responsividade, oferecendo uma experiência agradável para os visitantes.

---

## 📌 Sobre o Projeto
- **Tipo:** Website Onepage
- **Objetivo:** Apresentar os serviços e a identidade visual do Studio Alicia Costa
- **Tecnologias utilizadas:**  
  - HTML5  
  - CSS3  
  - JavaScript (se aplicável)  

---

## 🚀 Funcionalidades
- Estrutura **onepage** com navegação fluida
- Layout moderno e responsivo para diferentes dispositivos
- Seções dedicadas a:
  - Apresentação do Studio
  - Serviços oferecidos
  - Galeria/portfólio
  - Contato

---
